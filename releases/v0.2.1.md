# AIVideoPlayer v0.2.1

- 全屏自动隐藏鼠标；移动时恢复，静止 2.6 秒后再次隐藏，退出全屏恢复正常。
- 媒体探测和转码共用单任务队列，切换视频会停止旧任务，再处理最新视频；过期的排队请求直接跳过。
- 修复取消任务后正在播放的缓存可能被清理的问题。
- macOS 安装包补齐 AI 引擎需要的动态库，移除对本机 Homebrew 路径的依赖。
- Windows 安装包补齐 Microsoft C++、OpenMP 和 OpenSSL DLL，避免普通电脑缺少开发环境时 AI 引擎无法启动；增加包内版本、架构和引擎启动检查。
- 修正 pnpm 构建脚本配置及 CI 的 Node.js 版本。

## 下载

- `AIVideoPlayer-0.2.1-arm64-mac.zip`：macOS Apple Silicon，解压后将 App 放入「应用程序」。已做 ad-hoc 签名，未做 Apple 公证。
- `AIVideoPlayer.Setup.0.2.1.exe`：Windows x64 安装包，按安装向导操作；未做开发者证书签名。
- `SHA256SUMS.txt`：安装包 SHA-256 校验值。

本次同时提供 macOS 和 Windows v0.2.1 安装包。识别和翻译模型不内置，首次使用时按需下载。

## 验证与限制

TypeScript 检查、生产构建、32 项媒体／字幕／设置测试通过。macOS Electron 中 15 组编码样本的播放和拖动、解码失败回退、快速切换、全屏鼠标隐藏、字幕导入、设置持久化及缓存保护通过。包内三个 AI 引擎均可启动，安装包完整性及深度签名验证通过。
