# AIVideoPlayer v0.2.1

- 全屏自动隐藏鼠标；移动时恢复，静止 2.6 秒后再次隐藏，退出全屏恢复正常。
- 媒体探测和转码共用单任务队列。切换视频会取消正在进行的旧探测／转码，等待 FFmpeg 退出，再处理最新视频；尚未开始的过期请求直接跳过。
- 取消转换时继续保护当前播放的缓存，切换视频或卸载播放器时才释放，避免清理缓存中断播放。
- macOS 打包自动补齐 AI 引擎使用的外部动态库，并修正 Homebrew 绝对路径，附带 OpenSSL 许可证。
- 修正 pnpm 构建脚本配置，支持 pnpm 10.26+ / 11；CI 使用 Node.js 22。

## 本地安装包

`dist/AIVideoPlayer-0.2.1-arm64-mac.zip`：macOS Apple Silicon，已完成 ad-hoc 签名。AI 引擎复用 v0.2.0 包内二进制，补齐动态库后重新签名；不内置识别和翻译模型。

本次生成 macOS 安装包，未生成或验证 Windows 安装包。此文件不表示已发布 GitHub Release。

## 验证

- TypeScript 检查、生产构建、32 项媒体／字幕／设置测试通过。

- 全屏鼠标隐藏、移动后重置计时、退出全屏恢复，以及通过 preload/IPC 取消后的播放缓存保护通过。
- 安装包完整性与深度签名验证通过；包内三个 AI 引擎均可启动，未加载 Homebrew 路径下的动态库。
