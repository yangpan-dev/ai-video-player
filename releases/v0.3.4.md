# 熊猫播放器 v0.3.4 · 音频播放

原生 macOS 和 Vue / Electron 版加入完整的音频播放入口与界面，同步提供 Windows x64 更新。

## 更新

- 支持 MP3、M4A/M4B、AAC、WAV、FLAC、OGG、Opus、AIFF、WMA 等音频，可打开、拖入或从文件夹递归导入，音视频可混合加入播放列表。
- 纯音频显示音乐界面与文件名，支持播放 / 暂停、进度跳转、音量、倍速、进度恢复和连续播放。
- 语音音频可生成 AI 双语字幕，音频界面也支持字幕显示。原生版按引擎选择的字幕轨道和时间偏移显示字幕。
- 带封面的音频按音频处理；Vue / Electron 版对不兼容音频自动重封装或转换为 AAC，继续使用本地缓存。
- 保留 v0.3.3 的 AI 字幕稳定性修复、译文说明文字拦截，以及同一排的亮度、精简播放与全屏按钮。Windows 版此次同步这些更新。

## 下载

- `PandaPlayer-0.3.4-arm64-mac.dmg` / `.zip`：原生 macOS 完整安装包。
- `PandaPlayer-Electron-0.3.4-arm64-mac.zip`：Vue / Electron macOS 完整安装包。
- `PandaPlayer.Setup.0.3.4.exe`：Vue / Electron Windows x64 安装程序。
- `PandaPlayer.Setup.0.3.4.exe.verification.json`：Windows 包内版本与 AI 引擎启动验证记录。
- Windows 构建同时附带 `.exe.sha256` 和 `.exe.blockmap` 文件。
- `SHA256SUMS.txt`：各安装包的 SHA-256 校验和。

macOS 安装包适用 Apple Silicon、macOS 26 或以上，采用 ad-hoc 签名，尚未作 Apple 公证。两版应用名称相同，请择一安装到「应用程序」。Windows 安装程序适用 x64 Windows。安装包均包含播放和 AI 引擎，模型按需下载，也可复用已有目录。

## 验证

- TypeScript / Vue 类型检查、49 项 Node 回归测试、88 项原生核心检查。
- 实际音频 / 视频播放、暂停、跳转、倍速、音量、带封面音频、混合文件夹导入、兼容转换和音频字幕显示。
- 本地模型完成纯音频语音识别及中文翻译；两版 macOS 实际界面和应用签名检查。
- Windows 安装包由 Windows 构建环境生成，解包后检查版本、x64 程序、运行库及三个 AI 引擎在精简 PATH 下的启动。
