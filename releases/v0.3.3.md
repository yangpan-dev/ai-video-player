# 熊猫播放器 v0.3.3 · AI 字幕稳定性与播放控制

修复 AI 字幕生成中断、译文对应和模型说明混入字幕的问题，并同步调整两版播放控制栏。

## 更新

- 原生版关闭 Whisper 额外语言概率计算，修复静音被 VAD 过滤后识别引擎崩溃、界面显示「The network connection was lost」的问题。引擎异常退出会显示名称与退出原因。
- 翻译结果通过字幕 ID 与 JSON 结构约束对应，避免漏译后错配到其他字幕。原生版即时保存成功译文，未完成项最多单独重试两次，仍失败时保留原文并继续后续字幕；结束后可点击「重试翻译」补译。
- 两版拦截模型说明、分析和翻译开场白，单独重试对应条目；加载旧 AI 字幕时隐藏这类内容。原台词本身谈到用户、信息或翻译时保留正常译文。
- 两版的亮度、精简播放和全屏按钮放在同一排，亮度按钮可展开滑块。原生版新增精简播放，隐藏标题栏与列表，鼠标移动唤出控制栏，按 Esc 还原。

## 下载

- `PandaPlayer-0.3.3-arm64-mac.dmg` / `.zip`：原生 macOS 完整安装包。
- `PandaPlayer-Electron-0.3.3-arm64-mac.zip`：Vue / Electron macOS 完整安装包。
- `SHA256SUMS.txt`：以上安装包的 SHA-256 校验和。

适用 Apple Silicon、macOS 26 或以上。两版均包含播放和 AI 引擎，模型复用已有目录，无需重新下载。安装前退出旧播放器；DMG 中将应用拖入「应用程序」，ZIP 解压后替换应用。当前采用 ad-hoc 签名，尚未作 Apple 公证。

Windows 稳定版仍可从 [v0.3.1](https://github.com/yangpan-dev/ai-video-player/releases/tag/v0.3.1) 下载。
