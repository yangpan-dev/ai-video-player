# 熊猫播放器 v0.3.0

- macOS 原生版与 Vue / Electron 版统一改名为「熊猫播放器」。
- 共用重新生成的熊猫播放图标，突出播放三角、视频屏幕和进度条；覆盖 Dock、窗口、欢迎页与 Windows 安装程序。
- Vue 主界面精简为播放列表、视频与播放控制、AI 字幕及字幕菜单。模型管理、识别模式、亮度、字幕样式与同步、自动下一集、排序和缓存清理合并进设置；支持 `⌘ / Ctrl + ,`。
- 原生版收起重复的打开按钮，保留列表添加菜单、AI 字幕、设置及播放控制。高级画面、声音与字幕选项均在设置中。
- 保留旧版数据目录，兼容已下载的模型、列表、观看进度和字幕偏好。

## 下载与安装

- `PandaPlayer-0.3.0-arm64-mac.dmg` / `.zip`：macOS 原生版，自带 libmpv / FFmpeg 播放运行库及本地 AI 引擎。
- `PandaPlayer-Electron-0.3.0-arm64-mac.zip`：macOS Vue / Electron 版。
- `PandaPlayer.Setup.0.3.0.exe`：Windows x64 Vue / Electron 安装程序。
- `SHA256SUMS.txt`：安装包 SHA-256 校验和。

macOS 完整安装包面向 Apple Silicon，AI 引擎最低要求 macOS 26。两种 macOS 版本都安装为「熊猫播放器.app」，请选择其中一种。当前使用 ad-hoc 签名，未作 Apple 公证；首次打开可能需要在系统设置 → 隐私与安全性中允许。AI 模型按需下载，未内置于安装包；已准备模型后可离线使用。

## 验证

- TypeScript / Vue 类型检查与 32 项媒体、字幕和偏好测试。
- Electron 实际播放、拖动、格式兼容回退、字幕导入、偏好恢复、自动下一集及过期 AI 任务隔离。
- 原生 36 项核心检查、6 类真实媒体解码 / 拖动 / 预设检查、GPU 像素渲染与窗口测试。
- macOS 依赖闭包检查、严格签名验证与 DMG 校验。
- Windows 从安装程序提取应用，检查 x64 二进制与运行库，并在精简 PATH 中启动 Whisper / llama 引擎。

第三方运行库保留各自许可证与来源信息；原生包内 `Contents/Resources/PlaybackRuntime` 包含 libmpv 依赖来源与校验清单。
