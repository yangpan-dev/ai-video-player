# 熊猫播放器 v0.3.2 · 原生 macOS 全屏抖动修复

- 修复全屏进入 / 退出动画结束后，标题栏、播放列表与控制栏重新排版导致画面再次放大、缩小或位移的问题。布局在系统动画开始前准备完成。
- 修复原生标题栏安全区域在切换时额外改变顶部边距的问题；窗口调整尺寸时立即同步视频子视图布局。
- OpenGL 画布调整与视口尺寸更新采用同一上下文锁，渲染线程取得锁后再读取最新尺寸，避免一帧使用旧尺寸。
- 保留后台渲染、连续切换保护、全屏浮动控制栏与既有播放 / 字幕 / 模型数据。

## 下载

- `PandaPlayer-0.3.2-arm64-mac.dmg` / `.zip`：原生 macOS 完整安装包。
- `SHA256SUMS.txt`：安装包校验和。
- 本次更新针对原生版；Vue / Electron 版可继续使用 [v0.3.1](https://github.com/yangpan-dev/ai-video-player/releases/tag/v0.3.1)。

适用 Apple Silicon、macOS 26 或以上。采用 ad-hoc 签名，尚未作 Apple 公证。选择 DMG 将「熊猫播放器.app」拖入应用程序即可升级。

## 验证

用生成的 1080p / 4K H.264 视频连续进入、退出全屏，并直接记录视频边距：旧版四次切换出现四次动画结束后的额外跳变，修复后为零。还验证了过渡期间视频不越界、控制栏显隐不改变画面尺寸、持续出帧、重复点击保护、暂停重绘、字幕与设置窗口，以及包内依赖和签名。
