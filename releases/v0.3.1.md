# 熊猫播放器 v0.3.1

## 原生 macOS 全屏卡顿修复

- 视频绘制从界面主线程迁至独立串行渲染队列；合并连续帧通知，空闲时避免重复绘制。
- 取消持有 OpenGL 上下文锁时的帧时间等待，配合 mpv 的即时调度保持音画同步；窗口和 Retina 缩放更新与渲染互斥。
- 全屏控制栏改为覆盖显示，隐藏控制栏不再反复改变视频尺寸；防止连续点击重入全屏切换。
- 退出及关闭窗口时先排空渲染任务，再释放 libmpv 上下文和播放引擎。

## 分别设计的新图标

- 原生 macOS：蓝紫立体熊猫、紫色 AI 神经节点、蓝色视频屏幕和白色播放按钮。
- Vue / Electron：深色青绿几何熊猫、AI 电路节点、绿色播放按钮和视频进度条。
- 两版资源分开维护，覆盖 Dock、欢迎页、窗口和 Windows 安装程序。

## 安装包

- `PandaPlayer-0.3.1-arm64-mac.dmg` / `.zip`：macOS 原生版。
- `PandaPlayer-Electron-0.3.1-arm64-mac.zip`：Vue / Electron macOS 版。
- `PandaPlayer.Setup.0.3.1.exe`：Vue / Electron Windows x64 安装程序。
- `SHA256SUMS.txt`：安装包 SHA-256 校验和。

macOS 完整包面向 Apple Silicon，AI 引擎要求 macOS 26 或以上。采用 ad-hoc 签名，尚未作 Apple 公证。模型与既有资料库保留原目录，升级无需重新下载。

## 验证

- 1080p / 4K 连续四次全屏切换，检查主线程延迟、持续出帧、快速重复点击、实际帧缓冲像素及暂停后窗口重绘。
- 原生核心逻辑、多格式解码 / 拖动、GPU 画面预设和原片恢复、设置窗口、包内依赖闭包与签名检查。
- Vue / TypeScript 类型检查、媒体及偏好测试、真实 Electron 播放回归。
- Windows 安装程序提取检查，以及精简 PATH 中的 Whisper / llama 引擎启动验证。
