# AIVideoPlayer v0.2.0

本次更新改进视频兼容性、日常播放操作及字幕任务稳定性。

- 自动识别实际视频／音频编码，优先保留画质重封装或仅转换音轨；必要时转为 H.264 8 位 + AAC，播放失败自动回退一次。
- 记住音量、静音、亮度、倍速、字幕模式、字号和位置，切换视频或重启后保留。
- 导入或拖入 SRT / VTT 字幕，自动加载视频旁的同名字幕；支持 UTF-8、UTF-16 和常见中文编码，多行内容完整保留。
- 播放列表搜索、按名称自然排序、上一集／下一集、可选自动连续播放；播完后重置进度。
- 补齐全屏、静音、音量、打开文件、上下集等快捷键；设置面板可查看操作说明。
- 切换视频和取消任务会停止旧识别，旧字幕、翻译及进度不再覆盖新视频；最后一批字幕翻译完成后再保存。
- 修复缓存混用、损坏缓存、转换取消及大文件内存占用；清理临时识别音频。
- Windows 交叉构建自动附带 C++ / OpenMP 运行库，修复未安装编译工具链时 AI 引擎无法启动的问题。

## 下载

- `AIVideoPlayer-0.2.0-arm64-mac.zip`：macOS Apple Silicon，解压后将 App 放入「应用程序」。已做 ad-hoc 签名，未做 Apple 公证；首次打开可能需在「隐私与安全性」中允许。
- `AIVideoPlayer.Setup.0.2.0.exe`：Windows x64 安装包。AI 识别／翻译引擎为 CPU 版本，安装包未做开发者证书签名。
- `SHA256SUMS.txt`：安装包 SHA-256 校验值。

识别和翻译模型不内置，首次使用时在软件中下载。已有字幕的视频无需下载模型。

## 验证与限制

已通过 TypeScript 检查、29 项媒体／字幕／设置回归测试，以及 macOS Electron 中 15 组实际编码样本的播放和拖动测试。设置持久化、字幕导入、连续播放、解码失败回退及旧 AI 任务隔离均已在真实界面中验证。

Windows 包在 macOS 上交叉打包，已核对程序内容、x64 架构与 AI 引擎／FFmpeg 的 DLL 依赖，尚未在 Windows 实机上验证。需要完整转码的视频首次打开仍需等待；HDR 色调映射、多音轨切换及内嵌 ASS/PGS 渲染暂未实现。
