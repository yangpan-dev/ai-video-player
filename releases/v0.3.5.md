# 熊猫播放器 v0.3.5 · 识别续做与托盘托管

本轮改动集中在语音识别的容错、模型下载和打包流程。发布包为 Vue / Electron macOS 版（Apple Silicon）。

## 更新

- 识别支持中断续做：识别中途停止或关闭应用后，已完成的段落会写入断点；再次打开同一文件时界面显示「继续识别 N%」，点击即可接着识别，已完成的句子不重跑。断点用源文件大小与修改时间校验，文件被重新下载或剪辑后自动失效，改为从开头识别。
- 批量识别改为按静音处切片：先用 FFmpeg `silencedetect` 找出句子之间的停顿，再在停顿中点切分（最短 20 秒、长片约 20 段），避免切在句子中间导致 Whisper 在分片边界重复或编造文本；静音探测失败时退回固定时长切分。每片完成即落盘，流式识别每约 48 秒保存一次断点，取消与退出前同步写入。
- 字幕菜单新增「清除识别进度」，可丢弃断点从头识别。
- 播放列表与历史记录支持一键清空：侧栏搜索框右侧新增「清空」按钮并需二次确认，清空历史记录会同时删除这些文件的观看进度。
- 关闭主窗口时可选择「直接退出」或「托管到系统托盘」：在「设置 → 应用」设定默认行为，关闭时的询问框可勾选「记住我的选择」；托盘可唤起窗口，并补上单实例锁，避免重复启动。
- 模型下载支持国内镜像：按 hf-mirror、aifasthub、官方源轮换，20 秒无进度判定为停滞并切换源，保留 `.part` 文件断点续传，重试不丢进度；`HF_ENDPOINT` 可自定义下载地址。
- AI 引擎改用通用指令集编译（`GGML_NATIVE=OFF`、`GGML_AVX512=OFF`），产出的二进制不再绑定编译机 CPU；新增退出码解释，把 `3221225501` / `0xC000001D` 等错误翻译成可读原因。
- 新增 macOS 一键打包：`pnpm run build:mac:all` 依次检查工具链、安装依赖、编译引擎、构建、ad-hoc 签名、归档并输出校验和；同时新增单文件下载页 `site/download`。
- 修复 Windows 打包的两处卡点：`build:win` 显式使用本地 `electronDist`，避免 packaging 阶段联网下载 Electron 时静默卡死；`prepare-win-resources` 允许复用 `resources/bin` 下已有的 OpenSSL 运行库，不再强制要求 `OPENSSL_DIR`。
- 新增 `.gitattributes`，强制脚本类文件使用 LF，避免 Windows 检出后脚本无法运行。

## 下载

- `PandaPlayer-Electron-0.3.5-arm64.dmg`：Vue / Electron macOS 完整安装包（拖入「应用程序」即可，内含 FFmpeg 与 Whisper / llama 引擎）。
- `SHA256SUMS-mac-arm64.txt`：安装包 SHA-256 校验和。

原生 macOS 版与 Windows 安装包本轮未重新编译，仍使用 v0.3.4 的产物：

- `PandaPlayer-0.3.4-arm64-mac.dmg` / `.zip`：原生 macOS 完整安装包。
- `PandaPlayer.Setup.0.3.4.exe`：Vue / Electron Windows x64 安装程序。

macOS 安装包适用 Apple Silicon，采用 ad-hoc 签名，尚未作 Apple 公证。首次打开若提示「无法验证开发者」，请右键应用选择「打开」，或在「系统设置 → 隐私与安全性」中点击「仍要打开」。模型按需下载，也可复用已有目录。
