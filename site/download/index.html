Install

安装与首次使用

两个平台都是下载、安装、打开三步。安装包不带模型，首次运行在应用内点一次下载即可，之后完全离线。

macOS

  1. 在 Releases 页面下载 DMG（或 ZIP 解压），把 熊猫播放器.app 拖进「应用程序」。原生版与 Electron 版同名，只装一个。
  2. 首次打开若提示「Apple 无法验证…」，在「应用程序」里右键点图标 → 打开 → 再点打开。
  3. 若右键没有「打开」选项（macOS 15 及以上常见）：先尝试打开一次让它被拦截，再去 系统设置 → 隐私与安全性，在「安全性」一栏点 「仍要打开」。
  4. 打开后点「下载模型」：Whisper 语音模型约 1.6GB、翻译模型约 4.4GB，只需下载一次。
xattr -dr com.apple.quarantine /Applications/熊猫播放器.app
当前为免费 ad-hoc 签名、未做 Apple 公证，所以会出现上面的验证提示，属正常现象。上面那行终端命令可一次性去掉隔离标记，最省事。

Windows

  1. 下载 PandaPlayer.Setup.0.3.4.exe，双击运行。
  2. 安装向导里可以改安装目录；勾选桌面快捷方式后一路「下一步」即可。
  3. 若 SmartScreen 拦截（安装包未做代码签名），点 「更多信息」→「仍要运行」。
  4. 打开后在设置里下载识别模型与翻译模型，然后拖入视频即可播放并生成字幕。
本版已修复旧安装包在 Intel 12 代及以后 CPU（如 i5-13400F）上的崩溃： 旧版 AI 引擎编译时带入了 AVX-512 指令，而这类 CPU 已熔断该指令集，会在加载模型时报 0xC000001D / 退出码 3221225501。新包改为通用指令集编译，普通 x64 机器都能跑。
Features

它到底做了什么

整条链路都在本机完成：抽音轨、语音识别、翻译、叠加字幕，没有任何一步把视频传到服务器。

双语字幕实时生成

播放时流式识别，边播边出字幕，不必等整集处理完。

本地大模型翻译

Qwen2.5-7B 经 llama.cpp 在本机推理，译文不经过任何在线服务。

音频也能出字幕

MP3 / M4A / FLAC / WAV / OGG 等纯音频同样可以识别并翻译。

字幕可导出

识别结果能存成 .srt / .vtt，也能给同一个视频重新导入字幕。

完全离线

模型下好之后断网可用，适合笔记本外出或隐私敏感场景。

播放列表与历史

拖入整个文件夹批量导入，记忆观看进度，列表可一键清空。

内存建议 16GB 及以上（运行 7B 翻译模型）

Changelog

v0.3.4 · 音频播放

新增音频支持，Windows 包同步重新构建

2026-11-26
  • 支持 MP3、M4A/M4B、AAC、WAV、FLAC、OGG、Opus、AIFF、WMA 等音频，可打开、拖入或从文件夹递归导入，音视频可混合加入播放列表。
  • 纯音频显示音乐界面与文件名，支持播放 / 暂停、进度跳转、音量、倍速、进度恢复与连续播放。
  • 语音音频同样可以生成 AI 双语字幕。
  • 带封面的音频按音频处理；不兼容音频自动重封装或转 AAC，继续使用本地缓存。
  • 播放列表与历史记录支持一键清空（清空历史会同时清除对应观看进度）。
  • Windows 包已用通用指令集重新编译 AI 引擎，修复 Intel 12 代及以后 CPU 的 0xC000001D 崩溃。
